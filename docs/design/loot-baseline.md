# Loot e consumíveis — referência canônica

A [Sprint 3 — Sistema mestre de loot](../GDD/03_sistema_de_loot.md) substitui o baseline preliminar.

Raridades atuais: Comum, Mágico, Raro, Épico e Lendário. O módulo define cores, afixos, slots, consumíveis, taxas condicionais/absolutas, receitas únicas, exemplo JSON e integridade das recompensas.

Valores continuam experimentais; não há implementação ou balanceamento validado. Chefes concedem um Épico ou Lendário por vitória autorizada; receita e fragmento são únicos por campanha. Não usar a tabela antiga de quatro raridades.
